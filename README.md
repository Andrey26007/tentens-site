# TENTENS Tech — website prototype

Static prototype of the TENTENS Tech website (EN/UA): Home, Products, Services, Careers.
Plain HTML/CSS/JS — open `index.html` or serve the folder with any static host.

- `assets/site.css` — design tokens, layout, components
- `assets/site.js` — shared header/footer, EN/UA switch, binary text scramble, smooth scroll,
  pinned product scroll, live product interfaces, video loading

Brand videos and the logo load from tentens.tech. Product interfaces are illustrative.
